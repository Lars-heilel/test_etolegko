### Семантика локального состояния

Удалённые офферы — локальное состояние с 0% и кнопкой «Вернуть»; в Keitaro такой записи нет, при сохранении уходят только активные офферы. Дубли запрещены. Фиксация процентов фиксирует веса зафиксированных офферов; пересчёт идёт только между остальными активными; если зафиксированы все, новый получает 0%. Автосинхронизации нет — только кнопка «Получить потоки». Список кампаний — из Keitaro с пагинацией, поиск по названию локальный: в API только offset/limit. Технический раздел 7 не изменялся.
