# Keitaro Campaign Manager

Приложение для создания кампаний и редактирования офферов в Keitaro.
Backend — FastAPI + SQLAlchemy, frontend — React, база данных — PostgreSQL.

## Запуск

Нужны Python 3.12+, uv, Node.js 22+, pnpm 12+, Docker Compose и Make.
Команды выполняются из корня проекта.

1. Если `.env` ещё нет, скопируйте `.env.example` в `.env`.
2. Заполните в `.env`:
   - `KEITARO_BASE_URL` — адрес трекера, без `/admin_api/v1`;
   - `KEITARO_API_KEY` — API-ключ Keitaro.
     Остальные настройки можно оставить как в примере для локального запуска.
3. Выполните:

```bash
make install
make db-up
make migrate
make dev
```

Приложение: **http://localhost:5173**. Документация API: **http://localhost:8000/docs**.

Для следующего запуска достаточно `make db-up` и `make dev`.
Остановить приложение — `Ctrl+C`, базу — `make db-down` (данные сохраняются).

## Как пользоваться

### Создание кампании

Нажмите «Создать кампанию», введите название, выберите страну и найдите оффер через поиск.

Приложение создаст два потока: выбранная страна → Google, остальные посетители → оффер.
Редиректы выполняет Keitaro.

Название должно быть свободным, в том числе в архиве Keitaro. Если имя занято в архиве,
выберите другое или восстановите старую кампанию.

### Редактирование офферов

1. Откройте кампанию и нажмите **«Получить потоки»**.
2. Добавляйте офферы, удаляйте их или восстанавливайте кнопкой **«Вернуть»**.
3. При изменении состава проценты пересчитываются автоматически. Зафиксированные доли
   сохраняются: например, из 50/50 при фиксации первого и добавлении третьего получится 50/25/25.
   Если зафиксированы все активные офферы, новый получает 0%.
4. Нажмите **«Сохранить»**, чтобы отправить изменения в Keitaro.

До сохранения изменения находятся в локальной БД. Автоматической синхронизации нет.
«Получить потоки» заново загружает данные и может заменить несохранённые изменения.
Потоки без офферов пропускаются: если удалить последний оффер и сохранить,
после следующей загрузки поток исчезнет из редактора.

Если создание или сохранение завершилось частично, проверьте результат в Keitaro перед повтором:
уже выполненные изменения не откатываются.

## Разработка

- `apps/api` — backend, миграции и тесты.
- `apps/web` — frontend.
- `infra` — Docker Compose для PostgreSQL.

```bash
make test        # тесты backend и frontend
make lint        # проверка кода и структуры FSD
make typecheck   # проверка типов
```
